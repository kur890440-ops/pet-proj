Объясни, почему линейное изменение PWM от 0 до 255
не воспринимается человеческим глазом как плавное линейное
изменение яркости светодиода.

Раздели диапазон 0–255 на интервалы, в которых изменение
яркости воспринимается:
- сильно;
- заметно;
- слабо;
- почти незаметно.

Предложи способ сделать регулировку визуально плавной.

Ответ верни только в JSON следующего вида:

{
  "reason": "",
  "intervals": [
    {
      "from": 0,
      "to": 0,
      "perceived_change": ""
    }
  ],
  "solution": ""
}

Не более 1000 символов.
